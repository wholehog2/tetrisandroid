# Tetris (Kotlin + Jetpack Compose, Android 16 / API 36)
1. Ouvrir le dossier dans Android Studio (Narwhal ou plus récent) → Gradle sync.
2. Brancher le téléphone (débogage USB) ou lancer un émulateur API 36 → Run.
Contrôles : boutons ◀ ▶ (maintien = répétition), ↻ rotation (ou toucher le plateau), ▼ chute douce, ⇩ chute directe, RÉSERVE, II pause.
